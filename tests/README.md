# 交互验证

复用 v5 已有的四套 Playwright 脚本。

```bash
npm ci
npx playwright install chromium   # 首次安装浏览器
npm test
```

`npm test` 先运行静态隐私检查和构建，再自动启动本机预览服务，依次运行：

- `tests/回归.mjs`：决策、待采纳、写入失败、拼贴、导航、离线与回执。
- `tests/收藏.mjs`：旧入口、筛选、记录保存、字幕、图片、任务与来源关联。
- `tests/收藏-边界.mjs`：跨页面任务、缺失内容、回收、预览失效、草稿与断线。
- `tests/流程.mjs`：备注、AI 模拟、入库规则、自主处理、日切、日报、主体队列与项目回读。

任何失败断言都会返回非零退出码。测试使用新建浏览器上下文，只清理该上下文内的数据。截图写入 `output/playwright/`，由 `.gitignore` 排除。

可选环境变量：`URL`（使用已运行的预览服务）、`CHROMIUM`（自定义 Chromium 可执行文件）。

这些测试只验证合成数据下的前端行为，不覆盖真实采集、AI 服务、文件存储、设备或宿主集成。
