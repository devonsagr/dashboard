# 个人知识库与仪表盘平台

以 v5 为基线的独立本地项目。当前完成的是 **React 前端、浏览器内交互模拟与架构方向**；所有默认业务内容均为合成示例。

## 本地运行

需要 Node.js 20.19+ 或 22.12+（推荐当前 LTS）。在项目目录运行：

```bash
npm ci
npm run dev
```

开发地址：**http://127.0.0.1:5185**。Windows 可双击根目录的 `start-dev.bat`。端口被占用时会明确报错，不自动切换端口。

```bash
npm run typecheck       # TypeScript
npm run check:privacy   # 源码与文档静态检查
npm run build           # 类型检查 + 构建 dist/
npm run preview         # http://127.0.0.1:4185
npx playwright install chromium  # 首次运行交互测试时安装浏览器
npm test                # 隐私检查、构建与四套既有交互测试
```

## 当前边界

- 已有：卡片画板、规整与拼贴布局、卡片完整页、材料处理流程、收藏、群消息、日报、主体上下文、设置与模拟回执。
- 样例：行动、材料、项目、聊天、日记、画像、健康、费用、服务状态及 AI 结果。样例中的工程提交、部署与验收记录仅演示界面状态。
- 本地：布局、偏好、便签、打卡及手动输入保存在当前浏览器。存储键使用 `pkd.v5.` 前缀；不会读取旧项目的键。
- 待实现：真实文件读写、消息采集、平台登录、AI 调用、设备与账单接入、外部宿主挂载。架构文档描述方向，不代表这些能力已经接通。

## 隐私与示例

默认称呼为「访客」。真实项目、群名、作者、收藏链接、日记原话和个人画像已改写为合成内容；示例外链使用 `example.com`。示例文件路径只展示，不唤起外部知识库。

导入基线时未带入旧截图、原有构建产物、依赖目录或浏览器数据。新测试截图写入被 Git 忽略的 `output/playwright/`。后续本地输入不自动成为可公开的样例，分享前仍需检查新增内容。

## 代码结构

```text
src/
  workbench/  应用壳、画板、卡片外壳、注册协议、设置
  cards/      一张卡一个目录，包含 manifest、视图及私有数据
  data/       共享对象、样例、时间与配置
  ui/         共享界面组件
  styles/     原有 v5 设计系统
scripts/      隐私检查、浏览器测试启动
tests/        四套既有 Playwright 场景
docs/         产品、架构、前端、卡片与本地迭代说明
```

新增卡片沿用 `src/cards/_template/` 与 `src/cards/index.ts`，不另建平行框架。
