# 卡片 · 收藏（独立子项目）

> 文件夹 `src/cards/favorites/` · 卡片 id `favorites` · 完整页 `/c/favorites/*` · 承接旧卡：信息收集（旧 kind `collect` 自动迁移）· 依据：收藏专项文档 2026-10-17 版（FAV-01–30、S1–S12、AC-01–39）
> 全部是**合成样例**：标题带「示例·」，链接都是 `https://example.com/demo/...`，路径只展示不打开。没有真实账号、平台、转写、模型或文件写入。

## 1. 一句话

各平台的收藏 / 稍后看 / 书签进来成为**原始材料**；我读（正文、图片、字幕）、写一句短批注，选「直接入库」或「我自己处理」，就地预览后确认，得到一份**第一层记录**（入库资料 / 自己处理材料）；之后自己加工或让 AI 按批注整理、审查、归位到主题，明确起稿才有**我的知识稿**。任何一步都不等于「已理解」。

## 3. 前端表达（交接给下一阶段）

| 概念 | 在界面里 |
| --- | --- |
| 原始来源与版本 | 每条原始材料显示平台、来源性质（收藏 / 非收藏链接 / 人工补充）、出处（如 B站两个收藏夹名）、发布时间与进入本工具时间、原文版本号；「模拟：来源出了新版本」演示版本变化 |
| 入库资料 vs 自己处理材料 | 同一来源可各有一份，批注、状态、加工、历史各自独立；工作台顶部「原始材料 / 入库资料 / 自己处理材料」三层切换；记录页顶部能回到原始来源 |
| 阅读摘要 | 阅读页「本机摘要 · 原文选句」（不调模型）；「AI 优化」是主动按钮，结果只作阅读参考，不进入批注、预览、整理依据或知识稿 |
| 按批注整理 / 个人加工 / 知识稿 | 记录页依次：这份批注 → 自己加工（草稿）→ AI 辅助整理（轮次，可选参考笔记 ≤5、看过 / 接受 / 写意见再整理，过期轮次标出）→ 主题归位（仍是材料）→「我的知识稿」（明确起稿才有） |
| 多事实同时表达 | 列表和阅读页用一排「事实」标签：正文完整 / 部分、缺图 N、字幕状态、回复部分、任务中、已分流…；处理状态（待处理 / 以后读 / 已分流）单独；理解永远是本人另外标 |
| 预览 / 确认 / 回执 | 批注、归位、其他去向都是：编辑 → 预览（显示拟保存位置）→ 确认 → 回执（已保存位置）；预览后再改，旧预览失效；失败保留草稿；结果未知先「核对」；冲突不覆盖（走宿主统一写入语义，可在顶栏「样例」药丸里模拟） |
| 跟其他卡的往返 | 收件流里的收藏材料是投影，点「在收藏里打开 →」回来；转行动 / 挂到已有行动 / 送待采纳 / 关联项目都先预览，产物在记录页「去向」列出并可点开，产物上带回到收藏的来源 |

### 四条完整路径

1. **纯人工资料**：工作台「粘贴链接」→ 填 `https://example.com/demo/...` → 打开 → 读正文和图 → 直接入库，写一句 → 预览 → 确认 → 回到列表下一条 → 切「入库资料」找到它。失败分支：样例药丸设「写入失败」，确认后草稿保留。
2. **视频细读**：导入 → B站 → 勾两个示例夹 → 开始 → f02 显示两个夹 → 字幕搜索、双语 → 我自己处理 → 记录页自己加工 → 主题归位预览。不需要 AI。
3. **失败与跨页**：f15 字幕处理中 + 小黑盒补图任务运行 → 切到别的画板 → 顶栏「收藏任务」→ `settings` 设断线 → 任务窗显示截至时间 → 恢复「正常」→ 需处理里重试；当前在写的草稿不受影响。
4. **独立记录与保护**：f01 有 r01（入库资料）和 r02（自己处理材料）→ 回收 r01 → r02 仍可读 → 回收站恢复 → 改批注使旧预览失效 → 样例药丸设「结果未知」→ 先核对 → 回到正确记录。

## 7. 我做的判断与简化

- **不拆成多个卡**：收藏是一张卡 + 一个完整页（里面有工作台、阅读、导入、任务…），紧凑卡只放计数和最近几条。
- **工作台用双栏**（列表 + 阅读），而不是每条都跳新页；单条也有自己的地址 `i/:id`，可以分享和返回。
- **AI 只出现在两处**（阅读页「AI 优化」、记录页「AI 辅助整理」），都要主动点；保存批注从不经过 AI。
- **平台能力写在 `platforms.ts` 一张表里**，界面全部从表生成；以后加平台只加一行。
- **样例任务用一个计时器推进**（`store.ts` 的 `EFFECTS`），真实接入时换成后端推送即可。
- **没做**：真实文件选择器、项目「需求」类去向（只做了关联项目）、收藏专属冲突页面。
- **路径**：旧采集器的现有落点是 `系统/信息收集/原始导出/<平台>/`；收藏用的 `系统/收藏/…`、`知识库/主题/…`、`知识库/我的知识稿/` 都是**建议，待确认**——是否直接复用旧目录由后续本地阶段决定。
