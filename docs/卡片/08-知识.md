# 卡片 · 知识（知识景观 · 问题 · 知识库）

## 完整页

- `/c/knowledge`：节点树 + 关系图
- `/c/knowledge/n/:id`：节点正文、理解程度、挂载笔记、关联材料 / 行动 / 问题
- `/c/knowledge/questions`、`/c/knowledge/library`

## 你能做什么

- 标理解程度：懂 / 半懂 / 不懂 / 想拓展；接受或忽略 AI 建议（带理由）
- 编辑节点正文并保存
- 新问题、写回答
- 打开知识库文档，回到来源材料

## 结果怎么显示

- 理解程度显示“我标的 · 时间”，AI 建议单独标 AI
