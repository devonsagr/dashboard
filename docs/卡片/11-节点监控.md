## 你能做什么

- 看 1 天 / 3 天 / 7 天曲线（空洞 = 没采到）
- 立即采样、暂停 / 继续 / 停止采样
- 手动切换节点
- 开启 / 关闭自动路由（开启前确认）
- 看事件：切换、失败、采样、设置

## 结果怎么显示

- 当前节点、采样状态、最后完成时间、进行中进度（x / y）
- 离线时命令失败并说明
