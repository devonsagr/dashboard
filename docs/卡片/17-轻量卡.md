# 卡片 · 轻量卡

> 文件夹 `src/cards/clock/`、`src/cards/habits/`、`src/cards/countdown/`、`src/cards/sticky/`、`src/cards/recent-docs/`、`src/cards/quick-edit/`、`src/cards/embed/`

| 卡片 | 做什么 | 实例设置 | 数据 / 存储 |
| --- | --- | --- | --- |
| 时间 | 日期、星期、ISO 周次（香港时间） | — | 不读数据 |
| 打卡 | 按真实日期打卡，可补昨天；习惯可增删 | — | 本地；建议落盘 `系统/打卡/YYYY-MM.md`（建议，待确认） |
| 最近编辑 | 最近改过的 Markdown，点开在 Obsidian 打开 | 文件夹筛选 | 读 Vault 修改时间（样例） |
| 便签 | 随手贴；移除卡不丢文字，可从“全部卡片”找回 | — | 本地；建议 `系统/界面/便签.json`（建议，待确认） |
| 快捷编辑 | 钉一个 MD 文件直接编辑保存；冲突保留草稿 | 文件路径 | 样例文件（真实接入 = 读写该文件） |
| 倒计时 | 离某个日期还有几天（例：期末考试） | 名称、日期 | 不读数据 |
| 网页 | 嵌一个网页或本机小工具 | 地址 | 不读数据；有些网站禁止嵌入 |

> 以前的「月历」「日程」现在是视图：月历 = 复盘卡的月历视图（`review`），日程 = 今日行动卡的日程视图（`today`）。旧布局里的 `calendar-mini`、`agenda` 会自动迁移。

每张轻量卡也是独立文件夹（`src/cards/<id>/`），和大卡用同一套协议，只是 `light: true`。

规则：轻量卡头部更小，适合铺满画板空白；它们不产生业务对象（不会生成行动或请求）。
