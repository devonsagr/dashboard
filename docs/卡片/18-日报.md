# 18 · 日报（`daily`）

视图：**今日简报**（brief）/ **新内容推荐**（discover）。完整页 `/c/daily`。

- **来源覆盖**：今天（04:00 起）每个来源实际贡献了什么；分「实际贡献 / 部分 / 旧数据」，再列没有新内容、没读取、未接入。不宣称全源已取齐。
- **今天该关注**：群消息「关注」模式的消息（带「昨天的内容 · 今天取得」）、待决策、项目下一步。
- **流程待办**：没写备注 / AI 完、待我选 / 我自己处理 / 以后读 四个数，点进收件对应筛选。
- **建议**（AI）：每条带依据，「推到待采纳」后才进今日行动。
- **主体更新**：今天 AI 想写进主体文档的条目，去主体上下文处理。
- **健康与饮食**：只显示已有数据和缺口（C21 消费记录未接入）。
- **定稿**：写到 `flow.daily` 路径（样例，只出回执）；定稿后又进来的条数会标出。可撤回。
- **新内容推荐**：GitHub 热门 / 周报 / 关注作者。标「新」或几天前出现、内容本身的新旧与统计区间、与收藏/自己项目的关系；「收进收件」后走主线。

数据：`src/cards/daily/store.ts`（cardStore `daily`）。等后端：日报生成、定稿写文件、推荐抓取。
