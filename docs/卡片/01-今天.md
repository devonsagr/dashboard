# 卡片 · 今天（今日行动 · 待采纳 · 时间线）

> 文件夹 `src/cards/today/`、`src/cards/approvals/`、`src/cards/overdue/` · 承接旧卡：今日安排、今日安排（待采纳部分） · 旧 kind 自动迁移：`today-queue`、`agenda`、`custom-overdue` · 相关场景：S06 S08 S15 S26（见 [产品/04](../产品/04-场景与检验.md)）

一天要做的事放在一处：今天该做的、逾期的、还没排期的，以及 AI / 项目建议、等我采纳的事。

同一张卡的不同样子是「视图」：放到画板时选，之后在卡片「属性」里能换。卡片之间不互相 import，跳转一律用 `/c/<id>/…` 链接。

## 完整页

- `/c/today`：分组 逾期 / 今天 / 未排期 / 以后 / 已完成（未归档）/ 归档 / 已删除
- `/c/today/a/:id`：行动详情（标题、正文、日期时间、优先级、项目、来源、历史）
- `/c/approvals`：待采纳（按来源分组）
- `/c/today/timeline`：今天定了时间的行动按时间排

## 你能做什么

- 勾选完成 / 恢复；勾掉的当天仍留在卡里（删除线），第二天进“已完成”
- 新建、编辑标题与正文、改日期时间（日期留空 = 未排期）、优先级
- 归档、删除（可恢复）——删除不会抹掉历史
- 待采纳：采纳（按建议日期，没有则为今天）/ 不采纳（可写理由）/ 稍后 / 撤回到待采纳
- 行动详情里点来源，回到原材料 / 原请求 / 项目

## 结果怎么显示

- 每个按钮旁 `WriteNote`：正在写入 → 已保存（显示 `系统/行动/<id>.md`）/ 失败可重试
- 采纳后显示“已生成行动 a…”，可直接点开；重复采纳显示“已有对应行动，没有重复创建”
