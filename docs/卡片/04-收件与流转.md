# 卡片 · 收件与流转（随手记 · 收件流 · 待消化 · 流转 · 处理批次）

> 文件夹 `src/cards/inbox/`、`src/cards/quick-note/` · 承接旧卡：随手记 · 旧 kind 自动迁移：`inbox-stream`、`to-digest`、`flow-lanes` · 相关场景：S01 S02 S05–S08（见 [产品/04](../产品/04-场景与检验.md)）

所有进来的材料在一个地方：原文原样保存，读过、理解了、交给 AI、推送、落地，每一步都是我明确做的。

## 完整页

- `/c/inbox`：收件（按来源筛选、按主状态筛选、多选）
- `/c/inbox/m/:id`：材料详情（原文全文、两种时间、来源定位、媒体是否可用、QQ 上下文、AI 结果、去向、历史）
- `/c/inbox/batches(/:id)`：处理批次
- `/c/inbox/flow`：流转看板（新收到 → 已读 → AI → 已消化 → 已推送 → 已落地）

## 你能做什么

- 随手记：选类型（想法 / 问题 / 待办线索 / 摘录 / 原话）、原话保存（含换行）；`Ctrl J` 全局可用
- 标记已读 / 取消；写“我的理解”；**确认已消化**（要写一句理解）/ 撤回
- 稍后（1 / 3 / 7 天）、归档
- 去处：转为行动（去重）、挂到已有行动、推送到待采纳、入库到知识库、关联项目（参考 / 已确认需求）
- 多选 → 新建处理批次 → 确认发送给 AI；单条重试；重新读取 AI 状态

## 结果怎么显示

- 随手记保存成功显示 `系统/随手记/随手记收件箱.md#^块ID`；失败输入保留
- 材料的“去向”列出每个产出（行动 / 待采纳 / 知识 / 项目）并可点开
- 批次显示逐条状态：有结果 / 失败（原因）/ 不确定

## 等后端（Codex）

- 追加写随手记收件箱（带块 ID）
- 处理侧记录 `系统/收集处理/<来源>/`（已读、已消化、我的理解）
- 批次 `系统/收集处理/批次/` 与 AI 投递 / 回读

## v5 变更：备注优先的主线

- 材料页「处理」改成三步（`src/ui/flow.tsx`）：**① 备注**（必须先写才能交给 AI；也可只保存 / 以后读）→ **② AI 初处理**（按备注给摘要、要点、建议去向；失败可重发；备注改过会提示）→ **③ 我选**：A 直接入库（按落点规则预览路径，可单条改）/ B 我自己处理（划掉要点后「处理完了」= 已消化；可撤回）。
- 「其他去向」不冲突：转行动、挂到已有行动、推送到待采纳、关联项目。
- 收件卡泳道 6 列：收到 / 写了备注 / AI 初处理 / 我自己处理 / 去向 / 以后读。筛选：没写备注、待我选、我自己处理、以后读。
- 「稍后整理」改名 **以后读**；「待消化」= 选了「我自己处理」还没处理完的。
- 来自收藏的材料在收藏里处理（材料页给出跳转）。
