# 卡片 · QQ 群消息

> 文件夹 `src/cards/qq/` · 承接旧卡：QQ 消息 · 相关场景：S04（见 [产品/04](../产品/04-场景与检验.md)）

只收白名单群。逐群收集，一个群失败不影响其他群；读存档和新采集是两回事。

| 卡片 | id | 视图 | 状态 | 做什么 | 数据源 | 完整页 |

同一张卡的不同样子是「视图」：放到画板时选，之后在卡片「属性」里能换。卡片之间不互相 import，跳转一律用 `/c/<id>/…` 链接。

## 完整页

- `/c/qq`：群列表（白名单、上次收集、覆盖范围）、运行记录、消息（带上下文）

## 你能做什么

- 勾选群 → 收集所选群 / 只读存档
- 看逐群结果：成功（条数、批次路径）/ 失败（原因）
- 点消息进材料详情，看前后几条上下文（本条高亮）

## 结果怎么显示

- 每个群一行状态；失败的群可以重新勾选再收

## 等后端（Codex）

- NapCat 按需启停；`系统/信息接入/QQ/QQ消息收件箱.md` 索引与批次目录读取

## v5 变更：改为「群消息」（id 仍是 `qq`）

- QQ 与微信（P06，半自动，采集方式待定）合在一张卡。群按 **重要程度**（重要 / 一般 / 无所谓）和 **模式** 分：**关注**（今天必须知道的，如示例活动群）/ **钻研**（挑出知识库以外的话题）/ **只存档**。在设置 › 消息分组或本页「收集与分组」改。
- 视图：今日关注（带「昨天的内容 · 今天取得」，没推给你的群单列一行）/ 钻研（话题 + 为什么挑出来 + 看原消息 / 以后读 / 看过了）/ 收集。
