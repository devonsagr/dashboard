# 架构 07 · 规则边界

> 界面、后端、AI 都要守的底线。每条后面是在界面里能看到的地方。

## 关于“不知道”

1. **缺 ≠ 0**：没有数据显示“未知 / 未同步 / 未记录”，图表里画成虚线格，不画 0。（健康、复盘、使用时长、成本）
2. **不推断**：不根据“打开过”推断“已读”；不根据“AI 处理过”推断“已消化”；不根据“本地检查通过”推断“用户认可”。（材料主状态、项目验收）
3. **两种时间分开**：内容时间 vs 进入系统时间；设备记录时间 vs 同步时间；资料截至（asOf）vs 我们最后读取（lastReadAt）。
4. **来源要具体**：写到文件 + 块 / 标题 + 时间，不只写“来自 QQ”。信息不全时写“缺什么”。（R01）

## 关于“谁说了算”

5. **AI 只建议**：AI 的摘要、建议、理解程度、推荐选项都标 AI，需要用户点“接受 / 采纳”才生效。
6. **不自动承诺**：待采纳不会自己变成行动；请求不会自己被标“通过”；“已操作”回应标“待核实”。
7. **用户确认才入库**：知识库只在用户点“入库”时新增；不覆盖已有正文。
8. **原文只读**：材料 `text` 永远是原文；整理、批注写在处理侧。

## 关于写入

9. **成功才算**：只有后端确认才显示“已保存”；失败保留输入；不确定先重新读取；冲突保留草稿。（[03](03-写入语义与回执.md)）
10. **不自动重发**：失败 / 未知都等用户点“重试”。
11. **不重复生成**：同一来源再操作返回已有对象，并在回执里说明。
12. **运行时离线就说离线**：命令不排队、不假装成功，显示最后心跳。

## 关于布局

13. **布局 ≠ 内容**：删掉卡片 / 重置画板不删除用户写的内容；便签删除前会确认，孤立的便签内容在「全部卡片 › 轻量」里能找回（重新放回画板）。
14. **展示设置不是数据库**：画板、偏好不存行动、请求等业务数据。
15. **样例要标明**：样例数据处处带「样例」标记，顶栏有样例药丸；接入真实数据后去掉。

## 关于范围

16. **前端不碰文件**：本轮不读写任何 Vault 文件；路径只是显示。
17. **建议路径要标注**：凡不是现有落点的路径都带「（建议，待确认）」。
18. **不另起系统**：未来接入时先确认用户已有存储和来源；当前不绑定真实系统。
