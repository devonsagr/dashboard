# 架构 03 · 写入语义与回执

> 所有“会改东西”的按钮都走同一条路：`store.xxx()` → `write()` → 返回 `Receipt`。界面用 `useWrite()` 显示状态，用 `WriteNote` 写一行结果。回执汇总在 **设置 › 写入回执**（`/settings#receipts`）。

## 五种状态

| 状态 | 含义 | 界面怎么说 | 用户能做 | 本地数据 |
| --- | --- | --- | --- | --- |
| `pending` | 已发出，等待结果 | 「正在写入…」，按钮禁用防连点 | 等 | 不变 |
| `ok` | 确认写入 | 「已保存 · 09:30」+ 实际路径（可点开 Obsidian） | 打开结果 | **只有这时才改** |
| `failed` | 确认没写入 | 「没有保存：原因。你的内容还在。」 | **重试**（同一操作再发一次） | 不变，输入框保留 |
| `unknown` | 发出了但没收到结果 | 「不确定是否保存：原因。」 | **重新读取**（先看实际结果）/ 重试 | 不变 |
| `conflict` | 目标在别处被改过 | 「文件在别处被改过……草稿保留在这里。」 | **载入对方版本** / 覆盖（需确认） | 不变，草稿保留 |

## 规则

1. **成功才改**：`write(op,label,apply,opt)` 里的 `apply` 只在 `ok` 时执行。后端接入后，“成功”必须来自后端的确认（文件写入完成 / 运行时返回），不能是“请求发出了”。
2. **失败不丢输入**：随手记、我的理解、回应理由、日记正文等，失败 / 冲突时输入不清空（S05、S19）。只有 `ok` 后才清空或关闭。
3. **重试 = 同一操作**：`useWrite().retry()` 原样调用上一次的函数。后端应以 `op + targetId` 或请求自带的幂等键去重，避免重试变成两条。
4. **不重复生成**（S02、S08）：
   - 同一材料已有未删除行动 → 再“转为行动”返回已有那条（回执 `detail` 说明“没有重复创建”）；
   - 同一标题 + 同一组材料已推送 → 不再推；
   - 采纳 → 撤回 → 再采纳 → 复用原行动；
   - 已入库的材料再入库 → 返回已有路径；
   - 同一请求再“安排验收行动” → 返回已有行动。
5. **不自动重发**：`unknown` 时不自动重试，先让用户“重新读取”。
6. **本机运行时命令**（专注计时、节点监控）带 `runtime: true`：服务离线时直接 `failed`（「本机服务离线：命令没有送达」），不排队、不假装成功；界面显示最后心跳时间。
7. **只追加的写入**（随手记、调整顺序）`noConflict: true`：不会出现冲突，只可能成功 / 失败 / 未知。
8. **布局写入不产生回执**：画板布局、偏好是本地展示设置，与内容写入分开。

## Receipt 字段

```ts
interface Receipt {
  id: string;        // 回执编号
  op: string;        // 操作类别：capture / note / digest / approval / action-edit / respond / ningshi …
  label: string;     // 给人看的说明：「采纳：整理专注计时周报」
  at: ISO;
  status: 'ok' | 'failed' | 'unknown' | 'conflict';
  path?: string;     // 实际写到的文件（含 #^块ID）
  targetId?: string; // 生成 / 修改的对象 id
  detail?: string;   // 例如「已有对应行动，没有重复创建」
  error?: string;    // 失败 / 未知 / 冲突的原因
}
```

前端只保留最近 120 条（内存样例）。后端可以落成日志文件，路径待定（见 [05-路径与落点](05-路径与落点.md)）。

右上角「样例」药丸 › **模拟写入结果**：成功 / 失败 / 不确定 / 冲突；**模拟本机服务离线**。切到“失败”后在随手记里写一句再保存，可以看到输入保留、出现“重试”（截图 `30-随手记写入失败.png`）。切到“离线”后在专注计时里点开始，回执为失败（截图 `32-专注计时离线命令失败.png`）。

## 前端用法

```tsx
const w = useWrite();
<button disabled={w.busy} onClick={() => w.run(() => store.saveNote(id, text)).then((r) => r.status === 'ok' && setText(''))}>保存</button>
<WriteNote w={w} ok="已保存" onReload={reload} />
```
