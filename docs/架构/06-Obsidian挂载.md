# 架构 06 · 可选外部宿主

这是一份后续方向说明。当前项目独立运行在浏览器中，尚未安装到 Obsidian，也不假设用户已有插件、Vault 或固定安装版本。

如果未来选择 Obsidian 作为宿主，可以将应用作为一个标签页视图挂载，并继续复用卡片协议与共享对象。先检查目标插件的实际代码与配置，再决定集成方式。

| 项 | 当前前端 | 后续需要确认 |
| --- | --- | --- |
| 路由 | `HashRouter` | 宿主内可改 `MemoryRouter`，与宿主地址隔离 |
| 样式 | 全局主题令牌 | 将选择器收进独立根节点，确认主题变量映射 |
| 文件路径 | 纯文本示例，不打开文件 | 通过宿主能力打开用户明确配置的文件 |
| 布局与偏好 | `pkd.v5.` 浏览器键 | 是否改用宿主配置存储 |
| 数据 | 共享样例和各卡 `store.ts` | 真实来源、读取范围、写入与冲突回执 |
| 快捷键 | 应用内操作 | 检查宿主冲突与视图焦点范围 |
| 网页卡 | 用户填写地址后嵌入 | 核对宿主嵌入限制及外部打开方式 |

不在本轮创建插件、绑定文件目录或迁移个人数据。架构方向不能作为集成完成或实机验收的证明。
