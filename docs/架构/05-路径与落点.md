# 架构 05 · 路径与落点

本项目没有绑定任何真实文件目录、Vault、账号或工程服务。界面中的文件路径、仓库、提交、来源状态均为合成示例，只用于说明信息流与回执。

## 示例路径

| 对象 | 示例位置 | 当前行为 |
| --- | --- | --- |
| 行动 | `系统/行动/<id>.md` | 浏览器样例对象，不创建文件 |
| 材料 | `材料/<平台>/`、`系统/信息收集/` | 展示示例来源与多媒体缺口 |
| 项目 | `示例工程/<项目>/docs/project/` | 展示合成工程快照，不扫描磁盘 |
| 日记 | `示例数据/日记/YYYY-MM/上半月或下半月/YYYY-MM-DD/` | 三类示例文本及缺失、空白、失败状态 |
| 主体文档 | `示例数据/主体上下文/` | 路径配置默认为空，不绑定个人文件 |
| 健康与费用 | `示例数据/健康/`、`示例数据/成本/` | 合成数值及未知状态 |
| 流程输出 | `系统/收集处理/`、`知识库/` | 按设置计算示例落点，仅改浏览器数据 |

这些目录不代表已经存在的文件或后端约定。未来接入真实存储时，按用户选定的位置明确映射，保留来源、失败、未知和冲突语义。

## 浏览器存储

| 键 | 内容 | 重置方式 |
| --- | --- | --- |
| `pkd.v5.boards.v5` | 画板布局和实例设置 | 设置页恢复布局 |
| `pkd.v5.prefs.v2` | 外观、称呼与导航 | 设置页修改 |
| `pkd.v5.sample.v5` | 共享业务样例，按天生成 | 顶栏重置样例 |
| `pkd.v5.card.<id>.v1` | 卡片私有样例，按天生成 | 顶栏重置样例 |
| `pkd.v5.content.<id>.v1` | 本地便签与打卡 | 设置页单独重置 |
| `pkd.v5.settings.v1` | 日切、输出规则、主体路径和示例分组 | 设置页恢复默认 |
| `pkd.v5.sim.v1` | 写入结果与离线模拟 | 样例菜单 |
| `pkd.v5.lastBoard`、`pkd.v5.fav.ui` | 当前会话导航和收藏筛选 | 关闭会话 |

所有键都隔离在 `pkd.v5.` 前缀下。旧项目的浏览器数据不迁入；本地手动输入仍属于当前使用者，不能直接作为公开素材。
