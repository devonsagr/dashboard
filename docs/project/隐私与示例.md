# 隐私与示例

本地迭代基线只包含合成内容。项目没有真实账号、私有文件访问配置、业务采集器、模型密钥或个人数据目录。

保留场景与语义：原始材料、AI 结果、用户选择、失败、未知、冲突与历史快照。更换示例内容不应把这些状态合并为“成功”或“空”。

`npm run check:privacy` 检查文本中的本机绝对路径、外部知识库链接、常见密钥格式、非示例邮箱以及源码中的非示例外链。它不能自动判断所有自由文本和图片是否属于私人内容，新素材仍需人工审阅。

历史截图不进入基线。测试使用独立浏览器上下文，截图保存到被忽略的 `output/playwright/`；依赖目录、构建目录、环境配置和日志也不纳入版本管理。

界面中手动填写的便签、称呼、消息分组、路径和导入内容留在当前浏览器，不会自动写进源码。分享源码前检查差异；分享截图或导出文件前单独审阅其内容。
