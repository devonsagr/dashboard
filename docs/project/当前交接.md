# 当前交接 · v5 Obsidian 首版

日期：2026-10-18。版本：0.5.1。

## 当前实现

v5 脱敏前端基线已建立 Git 仓库。当前功能版增加独立 Obsidian 标签页，沿用现有 React、Vite、卡片协议和 UI，复用已安装 `jarvis-dashboard` 的 repository；随手记和日记使用 Obsidian Vault API。没有 Node 服务、额外端口或平行业务数据库。

接通行动、项目、待决策、随手记、日记、已有材料查看与转行动、原文打开，以及画板和外观偏好保存。具体功能及安装方法见根目录 README。首次首页摆放当前已接通的卡片，其他预设和卡片仍保留。

浏览器演示继续使用合成数据。真实模式从宿主取得业务数据，未接入卡片显示待接入，模拟设置与 AI 处理按钮不开放。实际文件内容和本机配置都不进入 Git。

上述自动化结果不代表用户验收，也不代表 AI、采集或设备集成已完成。公开库不记录真实 Vault 名称、绝对路径和实际内容。
