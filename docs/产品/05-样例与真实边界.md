# 05 · 样例与真实边界

## 一眼分辨

- 顶栏右侧黄色 **「样例」** 按钮常亮：只要它在，界面上的数据就都是样例。
- 页面标题旁、卡片角落的小黄标「样例」：这块内容来自样例数据。
- 卡片状态（全部卡片页）：**样例**（本轮用样例数据）/ **本地**（只存在浏览器，如便签、打卡）/ **未接入**（没有数据源，只有说明，如 B站倍速）/ **不读数据**（时间、倒计时、网页）。

## 真的 vs 假的

| 是真的（前端已实现） | 是样例 / 模拟（等后端） |
| --- | --- |
| 画板布局、卡片颜色、锁定、折叠、预设、导入导出（`pkd.v5.boards.v5`） | 所有业务数据：行动、请求、材料、项目、日记、知识……（共享 `pkd.v5.sample.v5` + 各卡 `pkd.v5.card.<id>.v1`；收藏卡的全部材料、记录、任务也是样例） |
| 便签文字、打卡记录（`pkd.v5.content.sticky.v1` / `pkd.v5.content.habits.v1`，浏览器本地） | 写入结果（成功 / 失败 / 不确定 / 冲突由「样例」菜单控制，延迟 0.4–0.7 秒） |
| 外观偏好（`pkd.v5.prefs.v2`） | 本机服务（专注计时 / 节点 / 使用时长）的在线状态与命令结果 |
| 香港时区的真实日期（今天、星期、月历、复盘区间都按真实日期算） | 健康数据、成本、接入源健康、诊断 |
| 去重、必填理由、未知不补零等**规则** | 采集 / QQ / AI 批次的运行结果 |

## 重置

- 样例菜单 › 恢复样例：业务样例回到初始（布局不受影响）。
- 设置 › 存储：分别清除布局、内容、样例、模拟设置。

## 接入后要去掉的东西

1. `src/data/sample.ts`（样例生成）与 `store.ts` 里的 `sim` 模拟 → 换成 DataPort 实现（见 [架构/04](../架构/04-接入层与DataPort.md)）。
2. `SampleMark` / 顶栏样例按钮：按接入源逐个去掉（某张卡的所有源都接通后，状态从「样例」改为不显示）。
3. 接入设置占位表单 → 真正保存。
