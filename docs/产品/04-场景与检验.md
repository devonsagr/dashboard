在 `npm run preview` 打开后按步骤操作。顶栏「样例」按钮可以切换**模拟写入结果**（成功 / 失败 / 不确定 / 冲突）和**本机服务离线**，用来演示异常路径。所有写入都能在 设置 › 写入回执 查到。

> 自动化检查：`/data/fn3.mjs`（Playwright）覆盖了 S10、S06/S26（采纳去重）、S01（失败保留输入）、S19（离线命令失败）、S20（自动路由明确开启）以及拼贴置顶 / 锁定 / 不越界 / 改色。最近一次全部通过。

| --- | --- | --- |
| S01 原话捕获 | `Ctrl J` 输入多行文字，选「问题」，`Ctrl Enter`；再把写入模拟改成「失败」重试一次 | 收件流出现原样多行；类型保存；失败时输入框内容还在，可重试；不会出现在今日行动 |
