## 旧版隐藏 / 兼容卡

「明日预览、工作负荷、生活、最近完成」不再铺成卡片：
- 明日预览 → 今日页「以后」分组 + 时间线；
- 工作负荷 → 复盘（排期 vs 完成）；
- 最近完成 → 今日页「已完成」分组（勾掉的当天仍在今日卡里，带删除线）；
- 生活 → 健康页 + 日记生活整理版。
