# 前端 04 · 怎么新增一张卡

> 目标：想到一个点子，复制一个文件夹、登记一行，就能在画板上看到它；写坏了也只坏它自己。

## 三步

1. 复制 `src/cards/_template/` 为 `src/cards/<你的 id>/`（id 用小写加短横，如 `reading-log`）；
2. 改 `manifest.ts` 里的 `id`、`name`、`folder`、`desc`、`icon`、尺寸；
3. 在 `src/cards/index.ts` 加一行 `import readingLog from './reading-log/manifest';` 并放进 `MODULES` 数组（位置 = 卡片库里的顺序）。

`npm run dev`，打开「全部卡片」或画板整理模式里的「添加卡片」，就能放上去。

## 协议（`src/workbench/cards/protocol.ts`）

```ts
// manifest.ts —— 只描述，不 import 界面
export default defineCard({
  id: 'reading-log', name: '读书记录', icon: BookOpen, category: '自定义', status: '样例', folder: 'src/cards/reading-log',
  desc: '最近在读的书和进度',
  w: 4, h: 5, minW: 3, minH: 3,
  views: [{ id: 'list', name: '列表' }, { id: 'shelf', name: '书架', w: 6, h: 4 }],   // 可选：同一张卡的不同样子
  props: [{ key: 'shelf', label: '书架', type: 'select', options: [...] }],          // 可选：实例设置
  data: { sources: [], storage: ['浏览器 localStorage › pkd.v5.card.reading-log.v1'], refresh: '实时', writes: '进度' },
  hasPage: true,
  load: () => import('./index'),
});

// index.tsx —— 实现
export default defineImpl({
  Card,          // 必须：画板上的正文，拿到 { inst, view, edit, setProps }
  Page,          // 可选：完整页，挂在 /c/reading-log/*，里面用相对 <Routes> 自己分子页
  Meta,          // 可选：卡头右侧小字（计数）
  Title,         // 可选：动态标题
  Crumb,         // 可选：面包屑最后一段
  Topbar,        // 可选：顶栏挂件（manifest.topbar = true 才加载），比如收藏的任务窗
  LibraryExtra,  // 可选：卡片库里这张卡下面的额外内容
});
```

## 数据放哪

| 你要的 | 用 |
| --- | --- |
| 只有这张卡用的数据 | `store.ts`：`export const S = cardStore('reading-log', () => ({ ... }))`；读 `S.use(d => d.x)`，写 `S.write('kind', '说明', () => { ... })`（自动有写入回执、失败 / 未知 / 冲突模拟） |
| 用户自己写的内容（不该被「重置样例」清掉） | `cardStore(id, seed, { content: true })` → `pkd.v5.content.<id>.v1` |
| 别的卡也要看到的东西（行动、材料、待采纳……） | `src/data`：`useData(db => ...)` 读，`store.xxx()` 写 |
| 这一个实例的设置（钉哪个项目、倒计时日期） | `props` / `setProps`，存在画板布局里 |

## 规则

1. `manifest.ts` 不 import 界面或数据（卡片库和画板只读它，要轻）；
2. 不 import 别的卡片文件夹；要跳过去用 `<Link to="/c/<id>/...">` 或 `useOverlay().open(...)`；
3. 没数据用 `<Empty>`，样例用 `<SampleMark>`；不要编数字（未知就写未知）；
4. 卡片里可以点的东西外层加 `data-nodrag`（不然拼贴模式下会被当成拖动）；
5. 样式放自己文件夹，类名加前缀；颜色只用令牌（`var(--fg)`、`var(--accent)`…），深色模式自动适配；
6. 写坏了宿主会显示「这张卡出错了 · 重试」，别的卡不受影响——但请别依赖它。

## 删掉一张卡

删文件夹 + 删 `src/cards/index.ts` 那一行。画板上已放的实例会显示「未知卡片」，整理模式里移除即可。

## 把旧 kind 迁过来

`aliases: { 'old-kind': { view: 'list' } }`：旧布局里的 `old-kind` 会自动变成这张卡的 `list` 视图。
