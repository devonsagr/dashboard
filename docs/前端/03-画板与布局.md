# 前端 03 · 画板与布局

## 两种布局

| | 规整 `grid` | 拼贴 `collage` |
| --- | --- | --- |
| 坐标 | 12 列网格，行高 44px，间距 12px（`Grid.tsx`） | 像素坐标 + 层级 `z`（`Collage.tsx`），吸附 8px |
| 重叠 | 不重叠，拖动时自动挤开、松手后向上挤紧（`compact` / `moveTo`） | 可以重叠，像冰箱贴 |
| 窄屏 | 画板宽 < 860px（Obsidian 分屏常见）改为两列流式、< 560px 单列；窄屏时不能拖动 | 保持自由摆放，位置夹进画板宽度内 |
| 适合 | 每天看的工作画板 | 书桌、灵感墙 |

一块画板只有一种布局；“整理”里可以切换，两套坐标各自保留（卡片 `x/y/w/h` 与 `c`）。

## 浏览与整理

- **浏览**：卡片可以直接操作（勾选、输入、按钮）；拼贴里点一下就置顶。
- **整理**（画板右上「整理」）：拍快照 → 拖动 / 调大小 / 锁定 / 换颜色 / 折叠 / 添加 / 移除 → **完成整理**（保存）或 **取消**（恢复快照）。
- 编辑条：添加卡片 · 恢复预设（只恢复布局，内容不受影响）· 导出 / 导入布局（JSON，全部画板）· 取消 · 完成整理。

## 拼贴：置顶、锁定、不出界（本轮修正）

- **置顶**：按下任何未锁定卡片，它的 `z` 变成当前最大值 + 1。
  - 整理时拖动：立刻置顶并开始拖；
  - 浏览时，或按在 `data-nodrag` 元素（按钮、输入框）上：**等这次点击结束后**（`pointerup` + `setTimeout 0`）再置顶。原因：置顶会让 DOM 重新排序，立即置顶会导致按钮收不到 `click`。
- **锁定**：位置、大小、层级都固定；不会被置顶，也不能被移除；卡片右上显示小锁，再点解锁。
- **不出界**：`clamp()` 保证 `0 ≤ x ≤ 画板宽 − 卡片宽`，卡片宽不超过画板；调大小时宽度最多到右边界。画板变窄（窗口缩小）时显示位置也会夹进来，但不改存储的坐标。
- 去掉了上一版的“层级条”。

## 卡片外壳（`CardShell.tsx`）

头部：图标 · 标题 · meta（如“3 条”）· 右侧按钮（悬停出现）：**⤢ 放大**（有完整页时）· **ⓘ 属性** · 整理时多出 **颜色**、**锁定**、**折叠**、**移除**（可撤销，内容不删）。
轻量卡（`light: true`）头部更小。属性面 `CardInfo.tsx`：数据源（可点进 `/c/sources/:id`）、存在哪、怎么更新、会不会写回、用户内容存哪、实例设置（`props`）。

## 卡片颜色（`tints.ts`）

10 种：默认、柠檬、沙、陶、蔷薇、梅、天、青、苔、石。存在 `CardInst.tint`。
实现：`--tint` 写到卡片上，背景用 `.card.tinted { background: color-mix(in srgb, var(--tint) 46%, var(--surface)) }`，深色模式降到 14%，便签用 88%，文字颜色不变，保证对比度。

## 布局与内容分开

- 布局只存：`id kind x y w h c props tint collapsed locked`（`kind` = 卡片 id，`props.view` = 视图）；
- 便签文字按 `noteId` 存 `pkd.v5.content.sticky.v1`；移除便签卡后文字还在，“全部卡片 › 轻量”里会列出孤立便签，可放回；
- “恢复预设”“删除画板”都不删内容。

## v5：拼贴的锁定层级

- 固定（锁定）的卡永远在最上层；**后固定的叠在先固定的上面**；未固定的卡点一下置顶，也只到未固定那层的最上面。
