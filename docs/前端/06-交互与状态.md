# 前端 06 · 交互与状态

## 路由（HashRouter）

只有四种地址：画板 `/`、`/b/:boardId`；卡片完整页 `/c/<卡片 id>/*`（子路由由那张卡自己的 `index.tsx` 决定）；`/cards`；`/settings`。v3 及以前的旧地址（`/today`、`/collect/:platform`、`/runtime/node`…）由 `workbench/app/App.tsx` 的 `LEGACY` 表自动转到新地址。

| 路径 | 页面 | 卡片 id |
| --- | --- | --- |
| `/` `/b/:boardId` | 画板（第一块画板是 `/`） | （宿主） |
| `/cards` | 全部卡片 | （宿主） |
| `/settings` `/settings#receipts` | 设置、写入回执 | （宿主） |
| `/c/today` `/c/today/a/:id` `/c/today/timeline` | 今日行动、行动详情、日程视图 | today |

## 统一的状态表达

| 情况 | 卡片里 | 完整页里 |
| --- | --- | --- |
| 读取中 | `Thinking`（小星 + “正在读取…”） | 同左 |
| 空（真的没有） | `Empty`：为什么空 + 下一步（例如“去收件看看”） | 同左 + 说明来源 |
| 未接入 | 卡片 `status: 未接入`，内容说明“需要什么源、在哪配置” | 源详情页 |
| 源离线 / 陈旧 | 头部小圆点变色 + “截至 HH:mm” | 横幅说明 + 最后读取时间 |
| 未知值 | “未知 / 未同步 / 未记录”，图表虚线格 | 同左 + 原因 |
| 写入中 | 按钮禁用，“正在写入…” | 同左 |
| 写入失败 | “没有保存：原因。你的内容还在。”+ 重试 | 同左，回执可查 |
| 不确定 | “不确定是否保存”+ 重新读取 / 重试 | 同左 |
| 冲突 | “文件在别处被改过……草稿保留”+ 载入对方版本 | 同左 |
| 运行时离线 | “本机服务离线 · 最后心跳 HH:mm”，控制按钮可点但会失败并说明 | 同左 + 重新连接 |
| 样例 | `SampleMark` 小标签 | 页头 `SampleMark` |
