# 前端 01 · 总览与目录

## 技术栈

- React 19 + TypeScript 5 + Vite 7；路由 `react-router-dom` 7（`HashRouter`，挂进 Obsidian 时换 `MemoryRouter`）；
- 动效 `motion`（可在外观里关闭）；图标 `lucide-react`；
- 不用 UI 框架、不用 CSS-in-JS：CSS 变量 + 类名（`src/styles/`；卡片自己的样式放卡片文件夹，类名加前缀，如收藏的 `fav-`）。

## 运行

```bash
npm ci
npm run dev         # http://127.0.0.1:5185
npm run typecheck   # 只做类型检查
npm run build       # 类型检查 + 打包到 dist/
npm run preview     # 预览打包结果 http://127.0.0.1:4185
```

Node 18+。`dist/` 需要本地服务打开。交互测试见 `tests/README.md`（Playwright，不在构建里）。

## 目录

```
src/
├─ main.tsx                 入口：引入样式、applyPrefs()、渲染 <App/>
├─ workbench/               宿主（不含任何卡片业务）
│  ├─ app/                  App（四种路由 + 旧地址转发）· Shell（顶栏、画板标签、面包屑、卡片顶栏挂件、toasts）
│  │                        CommandPalette（Ctrl K）· QuickCapture（Ctrl J）· overlay（放大动画、浮层）· prefs（外观）
│  ├─ board/                store（画板、预设、布局迁移）· Grid（规整）· Collage（拼贴）· CardShell（卡片外壳）
│  │                        CardInfo（属性面：视图、设置、数据说明）· tints（卡片颜色）
│  ├─ cards/                protocol（defineCard / defineImpl）· registry（读登记处、视图、别名）· host（懒加载、出错隔离）
│  └─ pages/                BoardPage（画板）· AllCards（卡片库）· Settings（外观、画板、存储、写入回执）
├─ cards/<id>/              一张卡一个文件夹：manifest.ts · index.tsx · 其余只属于它（见下表）
│  └─ index.ts              登记处
├─ data/                    共享对象：types · store（DataPort）· sample · time · cardStore（私有数据工具）
├─ ui/                      共享零件：ui（Chip、Section、Empty、Bars…）· objects（材料 / 行动 / 请求行）
│                           refs（来源与路径）· write（useWrite + WriteNote 写入状态）
└─ styles/                  tokens · base · shell · board · components · pages · v3
tests/                      Playwright 交互测试
docs/                       本文档
```
