# 前端 02 · 工作台核心

> 一条顶栏 + 内容区。**没有左右侧栏**（挂进 Obsidian 后侧栏归 Obsidian）。

## 顶栏（`workbench/app/Shell.tsx › TopBar`）

```
[✦]  [☀ 今日][▣ 项目][⇩ 输入][📖 知识][♥ 身体与工具][★ 书桌][◇ 拼贴][+]      🔍  ✎  ▦  样例  ●接入源  ⚙
```

| 区域 | 说明 |
| --- | --- |
| 画板标签 `BoardTabs` | 每块画板一个标签，带图标；点击切换；右键（或标签旁 ⋯）打开管理。标签太多时横向滚动 |
| 下拉样式 `BoardMenu` | 外观 › 画板导航可改为“下拉菜单”：只显示当前画板名，点开列出全部 |
| `+` 新建 `NewBoard` | 从预设新建（今日 / 项目 / 输入 / 知识 / 身体与工具 / 书桌 / 拼贴）或空白（规整 / 拼贴） |
| 管理 `BoardManage` | 改名、换图标（8 种）、左移 / 右移、删除（至少保留一块；只删布局不删内容） |
| 🔍 搜索 | `Ctrl K` 命令面板：画板、卡片完整页、项目、行动、请求、材料、接入源；↑↓ 选择、Enter 打开 |
| ✎ 随手记 | `Ctrl J`：类型（想法 / 问题 / 待办线索 / 摘录 / 原话）+ 原文；保存失败不清空 |
| ▦ 全部卡片 | `/cards`：唯一的汇总入口；按类别筛选；“放到当前画板”；孤立便签可放回 |
| 样例 `SamplePill` | 说明这是样例；**模拟写入结果**（成功 / 失败 / 不确定 / 冲突）、**模拟本机服务离线**、重置样例 |
| ●接入源 | 汇总健康点（有离线 / 陈旧时变色），点开 `/c/sources` |
| ⚙ 外观 `SettingsMenu` | 浅色 / 深色 / 跟随系统；底色 暖纸 / 中性 / 跟随 Obsidian；强调色 5 种；密度；动效；画板导航 标签 / 下拉；称呼；更多 → `/settings` |

## 面包屑（`CrumbBar`）

完整页顶部一条细栏：`← 今日 › 待我决策 › d03`。
- “←” 回到**进来之前的画板**（`sessionStorage['pkd.v5.lastBoard']`）；
- 规则来自各功能清单的 `crumbs`：`{ base: '/c/decisions', card: '待我决策', sub: (seg) => … }`。

## 放大（`overlay.tsx`）

卡片 ⤢ → 记录卡片位置 → `ExpandGhost` 从卡片位置放大到全屏 → 进入完整页路由。动效关闭时直接跳转。

## 消息（`Toasts`）

轻提示（“已导入布局”“已移除，可撤销”），自动消失，可带“撤销”。写入结果**不用 toast**，用就地的 `WriteNote`（结果需要停留，且失败要能重试）。

## 设置页（`/settings`）

分区：外观 · 画板 · 样例数据 · 本地存储位置 · **写入回执**（`#receipts`，最近 120 条，可点开路径）。
