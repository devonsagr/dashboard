# 前端 05 · 设计系统

> 安静、极简：暖白纸面、细线、少量强调色；不用渐变、不用大面积色块；状态靠小标签和小圆点表达。

## 令牌（`styles/tokens.css`）

| 组 | 变量 |
| --- | --- |
| 底色 | `--bg`（页面）`--bg-sunk`（凹陷区）`--surface`（卡片）`--surface-2`（卡片内分区）`--hover` `--active` |
| 文字 | `--text` `--text-2` `--muted` `--faint` |
| 线 | `--line` `--line-strong` |
| 强调 | `--accent` `--accent-soft` `--accent-bg` |
| 语义 | `--ok/-bg` `--warn/-bg` `--bad/-bg` `--info/-bg` `--ai/-bg` |
| 形状 | `--r-sm` `--r` `--r-lg`；`--shadow-sm` `--shadow` `--shadow-lg` |
| 字体 | `--font-sans`（系统中文字体）`--font-serif`（大数字、标题）`--font-mono`（路径、时间、编号） |
| 动效 | `--dur` `--ease`；外观里关掉动效后 `MotionConfig reducedMotion="always"` |

## 底色（`data-palette`）

| id | 名称 | 说明 |
| --- | --- | --- |
| `warm` | 暖纸（默认） | `#faf9f5` 页面、`#f0eee6` 凹陷 |
| `neutral` | 中性 | 贴近 Obsidian 默认主题的白和灰 |
| `obsidian` | 跟随 Obsidian | 映射 `--background-primary` `--background-secondary` `--text-normal` `--text-muted` `--background-modifier-border` 等；浏览器里用后备色 |

每种都有深色版本（`data-theme="dark"`）。

## 强调色（`data-accent`）

陶土 `#c96442`（默认）· 石墨 `#3d3d3a` · 苔绿 `#5b7a4c` · 靛蓝 `#4f5fa8` · 跟随 Obsidian（`--interactive-accent`）。

## 语义色用法

| 类 | 用在 |
| --- | --- |
| `tone-ok` | 正常、已保存、已完成、通过 |
| `tone-warn` | 陈旧、部分、逾期、待核实 |
| `tone-bad` | 离线、失败、缺文件、受阻 |
| `tone-info` | 已消化、信息性状态 |
| `tone-ai` | AI 产出（摘要、建议、处理中） |
| `tone-accent` | 新收到、需要我、当前选中 |
| `tone-neutral` `tone-faint` | 一般 / 未核验 / 计划中 |

## 卡片颜色

10 种柔和底色（见 [03-画板与布局](03-画板与布局.md)），只改背景，不改文字与语义色。

## 密度

`comfortable`（默认）/ `compact`：缩小卡片内边距与行高，适合 Obsidian 窄分屏。

## 写作口吻

- 短句、动词开头：“确认已消化”“安排验收行动”；
- 说清后果：“删除（可恢复）”“移除（内容不会删）”；
- 不说“智能”“魔法”；AI 产出只说“AI 建议”；
- 状态用“未知 / 未同步 / 未记录”，不用“0”或“—”掩盖。
